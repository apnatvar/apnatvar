### 🏗️ Selected Work

#### [Open Workout](https://github.com/apnatvar/open-workout)

An open-source workout builder for gym trainers, personal trainers, and fitness professionals. It supports AI-assisted workout design, simple client sharing, and an MCP server that exposes its workout-building capabilities to compatible AI clients.

#### [ELZA International](https://elza.co.in/)

A responsive, content-first website where performance, SEO, asset optimisation, and visual consistency were treated as core product requirements. The design uses varied section compositions within a deliberately limited brand palette. [Read the case study](https://github.com/apnatvar/apnatvar/blob/main/Elza%20Case%20Study.pdf).

#### [Autonomous Urban Mobility](https://github.com/apnatvar/adaptive-traffic-control/)

My final-year engineering thesis explored adaptive traffic optimisation using satellite intelligence instead of hardware-heavy conventional infrastructure. The proof of concept framed the system as a scalable B2B optimisation engine for smart-mobility and navigation ecosystems. [Read the thesis](https://github.com/apnatvar/adaptive-traffic-control/blob/main/Thesis.pdf).

#### [Excel Automation](https://github.com/apnatvar/deliveredProjects/blob/main/ConsolidateExcel.py)

A standalone Python application for consolidating financial data covering more than **$10M in yearly transactions**. It reduced a five-day process to roughly **17 minutes** and generated 11 reports for downstream review.

#### [Chattybot](https://github.com/apnatvar/chattybot)

A self-hostable, multi-tenant website chatbot with an embeddable customer widget. It uses tenant-specific pages and product catalogues, encrypted per-site credentials, resilient fallbacks, and a production-oriented Docker deployment workflow.
